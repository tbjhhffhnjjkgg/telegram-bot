# Fronzan ArizonaRP Bot

Профессиональный Telegram-бот личного кабинета для сервера Fronzan ArizonaRP с красивым интерфейсом, полным управлением и удобными способами оплаты.

- Красивое отображение баланса и информации
- ✏️ **Редактирование профиля** прямо в Telegram
- Изменение имени без перезагрузки
- Просмотр статистики аккаунта

### 💰 Два способа пополнения баланса

#### 💳 YooKassa (прямая оплата)
- SBP (система быстрых платежей)
- Банковская карта
- ЮMoney
- Мгновенная зачисление

#### 👤 Через владельца (с подтверждением)
- Пользователь создаёт заявку
- Владелец получает уведомление
- Подтверждение одной кнопкой
- Автоматическое зачисление баланса

## 📋 Установка

### 1. Подготовка
```bash
# Создайте виртуальное окружение
python -m venv .venv

# Активируйте (Windows)
.venv\Scripts\activate

# Активируйте (Linux/Mac)
source .venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Конфигурация
Скопируйте `.env.example` в `.env` и заполните:

```env
TELEGRAM_TOKEN=ваш_токен_от_BotFather
OWNER_USERNAME=Frag_History
OWNER_CHAT_ID=ваш_id_в_телеграме
BOT_NAME=Fronzan ArizonaRP
YOOKASSA_SHOP_ID=ваш_shop_id (опционально)
YOOKASSA_SECRET_KEY=ваш_secret_key (опционально)
YOOKASSA_RETURN_URL=https://example.com/success (опционально)
YOOMONEY_PAYMENT_URL=https://ваша-официальная-ссылка-оплаты (опционально)
```

### 4. Запуск
```bash
python main.py
```

## 🔑 Получение токенов

### TELEGRAM_TOKEN
1. Найдите бота **@BotFather** в Telegram
2. Напишите `/newbot`
3. Ответьте на вопросы
4. BotFather выдаст вам токен

### OWNER_CHAT_ID
1. Найдите бота **@userinfobot** или **@getmyid_bot**
2. Напишите `/start`
3. Бот покажет ваш ID

### YooKassa (опционально)
1. Зарегистрируйтесь на https://yookassa.ru
2. Перейдите в личный кабинет
3. Получите SHOP_ID и SECRET_KEY

### ЮMoney без YooKassa
Для оплаты картой или СБП укажите в `YOOMONEY_PAYMENT_URL` официальную платёжную форму/ссылку ЮMoney, созданную в вашем аккаунте. Бот покажет её пользователю кнопкой «Оплатить картой / СБП».

Если у вашей формы нет СБП или оплаты картой, используйте YooKassa либо другой эквайринг: обычный номер кошелька ЮMoney сам по себе не является эквайринговой страницей и не даёт боту автоматического подтверждения оплаты.

Для ручного перевода укажите `YOOMONEY_WALLET` и `YOOMONEY_PHONE`. Пользователь переводит деньги, нажимает «Я оплатил», а владелец проверяет перевод в кошельке и подтверждает заявку.

Этот способ ручной: бот не видит факт перевода автоматически, поэтому не подтверждайте заявку без проверки в кошельке. Для автоматизации вместо YooKassa можно подключить другой эквайринг с API и webhook, например Robokassa, CloudPayments или платёжный модуль банка. Тогда потребуется отдельная интеграция статусов платежа и подписи webhook.

## 📱 Использование

### Для пользователя
- `/start` — открыть профиль
- **Редактировать профиль** — изменить имя
- **Пополнить баланс** — выбрать способ оплаты
- **Услуги/Товары** — просмотр каталога
- **Поддержка** — отправить сообщение

### Для администратора (@Frag_History)
- **ПАНЕЛЬ АДМИНИСТРАТОРА** — управление всем
- **Пополнить баланс пользователю** — ввести `@username 250`
- **Заявки на пополнение** — подтвердить/отклонить
- **Список пользователей** — просмотр всех
- **Управление товарами** — добавлять товары
- Добавление: `Название|Цена|Описание`
- Для фото используйте полный формат: `Название|Цена|Описание|URL-фото`
- Изменение: откройте **Каталог товаров** и нажмите **Изменить**

В каталогах **Аренда** и **Товары** нажатие на позицию открывает её карточку с фотографией, назначением, описанием и ценой. URL должен вести прямо на изображение (`.jpg`, `.png` и т. п.).
- **Настройки бота** — информация о боте
- **Статистика бота** — пользователи, доход и активные заявки
- **Рассылка** — отправка сообщения всем зарегистрированным пользователям

## 🗄️ База данных

SQLite база с таблицами:
- **users** — пользователи, балансы
- **products** — товары
- **services** — услуги
- **payment_requests** — заявки на пополнение (pending/confirmed/rejected)

## ⚠️ Важно

- Никогда не публикуйте `.env` с реальными токенами!
- После утечки токена немедленно отзовите его через `/revoke` в BotFather и выпустите новый
- YooKassa работает только с реальными ключами
- Владелец должен иметь username точно как в `OWNER_USERNAME`
- БД сохраняется в `bot_data.db`
