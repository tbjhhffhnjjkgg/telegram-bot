# Fronzan ArizonaRP Bot

Телеграм-бот личного кабинета для сервера Fronzan ArizonaRP с профилем пользователя, панелью владельца, оплатой через YooKassa, оплатой через владельца, каталогом товаров и техподдержкой.

## Установка

1. Создайте виртуальное окружение.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните значения.
4. Запустите бота:
   ```bash
   python main.py
   ```

## Переменные окружения

- `TELEGRAM_TOKEN` — токен бота.
- `OWNER_USERNAME` — логин владельца (`Frag_History` по умолчанию).
- `OWNER_CHAT_ID` — ID чата владельца для уведомлений поддержки и подтверждения оплат.
- `BOT_NAME` — название бота: `Fronzan ArizonaRP`.
- `YOOKASSA_SHOP_ID` — ID магазина YooKassa.
- `YOOKASSA_SECRET_KEY` — секретный ключ YooKassa.
- `YOOKASSA_RETURN_URL` — URL после успешной оплаты.

## Функции

- **Личный кабинет** — профиль с именем и балансом пользователя
- **Панель владельца** — управление для `Frag_History`:
  - Прямое пополнение баланса пользователю по имени
  - Просмотр и подтверждение заявок на пополнение
  - Добавление товаров
  - Просмотр каталога товаров
- **Два способа пополнения баланса**:
  1. **Через YooKassa**: SBP, банковская карта, ЮMoney (прямые платежи)
  2. **Через владельца**: пользователь создаёт заявку → владелец подтверждает → баланс зачисляется
- **Выбор способа оплаты**: SBP, карта, ЮMoney
- **Каталог товаров и услуг** — аренда и покупка
- **Техподдержка** — сообщение рабочего времени 09:00–21:00 + отправка обращений владельцу
- **Хранение данных** — SQLite БД с пользователями, товарами, услугами, заявками на оплату

## Важно

- **YooKassa**: оплата работает только при корректных ключах (`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`) в `.env`.
- **Оплата через владельца**: 
  - Пользователь указывает сумму в чате.
  - Владелец получает уведомление с кнопками подтверждения/отклонения.
  - После подтверждения баланс автоматически зачисляется.
  - Заявки хранятся в БД с статусами: `pending`, `confirmed`, `rejected`.
- **Прямое пополнение владельцем**: владелец может сразу пополнить баланс конкретному пользователю через панель без заявки.
